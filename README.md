# Book Illustration Studio

A local full-stack web application for turning book text into a
five-step AI illustration pipeline.

## Pipeline

1. Style
2. Characters
3. Portraits
4. Chapters
5. Illustrations

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
- AI: Gemini API
